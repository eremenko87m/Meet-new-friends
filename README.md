# World Friends Club — speaking game

Готовая статическая игра: телефон-подсказка с диалогом и два игровых телефона, по восемь карточек на каждом. Карточки появляются в случайном порядке без повторений, пока не закончится текущая восьмёрка. Кнопка **NEW PAIR** меняет обе карточки одновременно, а кнопки **NEW CARD** — каждую по отдельности.

## Как опубликовать через GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите **всё содержимое этой папки** в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.

Игра не использует сервер, базу данных или внешние библиотеки. После публикации она работает как обычная веб-страница.

## Файлы

- `index.html` — структура игры и разговорная опора;
- `styles.css` — оформление и адаптация под разные экраны;
- `app.js` — случайная выдача карточек;
- `assets/cards/` — 16 отдельных карточек.
